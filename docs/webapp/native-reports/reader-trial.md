# Native reports — reader trial

Prepared 1 November 2026. **Status: prepared; no human trial recorded.**
Use the synthetic Part 4C workspace. This checks whether the report communicates
its findings and limitations. It does not approve the financial result. Read the
page first; keep the separate answer guide closed until answers are recorded.

Record reviewer, date, browser/device, report/run ID, answer, evidence location,
whether help was needed and any confusing wording for each task. “Unavailable”
is a valid answer when the report explains why. Do not use terminal logs.

| Task | Open saved run | Questions to answer in plain language |
| --- | --- | --- |
| R1 · Company research | `research-example` | What period and data basis are shown? How did revenue change? Which valuation assumptions need review? Is the model value an external price target? Are consensus estimates or named-broker reports actually available? |
| R2 · Monitoring | `monitoring-example`, then `monitor-pending` and `monitor-approved` | Which original-cycle item breached which policy, and on what observation date? Why can surfaced items differ from retained breaches at export? What does the pending proposal change, and has it already changed the effective view? Does a saved correction decision establish authenticated financial approval? |
| R3 · Past events | `events-example`, then `events-ten` | How many historical cases and issuers are represented? What does the mean diagnostic return describe? Does it forecast the next event? Why is inference held even when a sample count check passes? Is the event-relative path available? |
| R4 · Company news | `news-example`, then `news-failed` and `news-unscored` | Which stories were retained and what text was available? Is a published tone result available? Does a diagnostic zero mean a neutral conclusion? How do no usable input and scorer failure differ? |
| R5 · Financial close | `close-example`, then `close-corrected` and `close-yearend` | Reconcile budget to actual. Explain the difference between a cost increase and its effect on profit. Is the year-end estimate guaranteed or approved? What changes after the earlier-period correction? What does a closed year mean for the remaining forecast horizon? |

For each family, use the chart keyboard controls, open a selected figure's source,
and return. Open the complete reading copy and locate the same figure, period,
restriction and evidence reference. Confirm that the copy includes more than the
current interactive page/filter where applicable. Record any lost reading context.

Acceptance requires the reviewer to identify the correct scope, key result,
material restrictions and attribution in every family without misleading conclusions.
Clarification or incorrect answers require a wording/design follow-up; do not turn
an unanswered task into a pass.

## Separate physical-accessibility and print checks

These checks are also **pending**, not prerequisites for reading the questions.

1. On a physical touch device, select chart points, inspect exact values, scroll
   large tables/plots, open source details and return without losing context.
2. With a screen reader, review heading order, report states, chart control names,
   selected-value announcements, table headers, source navigation and error focus.
3. For each baseline family, use **Print reading copy**, save a PDF through the
   browser's normal print interface and inspect every page. Reconcile measures,
   plot legends, full tables, periods, withheld states and evidence references.
   Check repeated headers, clipping, page breaks and long identifiers. Record
   browser, print settings, file hash, page count and any failure. Use a larger
   paginated case too; a successful first page is insufficient.
4. If physical printing is required, inspect an actual printed sample separately.
