KEYSTONE
Multi-agent finance & markets analytics

One platform. Four agents. One analytical spine.

Keystone is a set of finance agents that share one foundation — the same data access, the same agent loop, the same statistical tools. Each agent solves a different problem; the shared spine is what makes them one system rather than four scripts.

The LLM never does the math. Every figure — every DCF, regression, z-score, CAAR and probability — comes from deterministic Python. The model chooses which tool to call, reads the result, and writes the narrative. It never computes in its head, so every number is auditable.
